# 2026-01-23 Wadachi 更新メモ

## 実施した主な作業
- Node.js を `nodebrew use v20.19.0` で 20.19.0 に統一し、対応する `node_modules` をクリーン再インストールした。
- 旧 `iohook` 依存を完全に排除し、Node 16+ をサポートする `uiohook-napi` へ差し替え。
  - `src/main/main.ts` で `uIOhook` の API を使ってキーボードイベントを購読し、`handleKeyboardEvent` 経由でレンダラに送信するよう変更。
  - `package.json` の dependencies と `pnpm.allowedBuiltDependencies`/`onlyBuiltDependencies` を更新。
- Vitest の設定とテストを整備。
  - `vitest.config.ts` で `include/exclude` を明示し、`dist/**` を除外。
  - `src/shared/__tests__/keystrokeBuffer.test.ts` に `vi.setSystemTime(0)` を追加してフェイクタイマーの基準を固定。
  - `jsdom` を devDependency に追加し、`pnpm test` が `jsdom` 環境で通ることを確認。
- キーマッピング不一致を修正。
  - `uiohook-napi` が返すスキャンコード（OS ネイティブの scancode）と、旧 `iohook` が参照していた USB HID Usage ID の番号体系が異なっていたため、押したキーと表示がずれていた。
  - `src/shared/keyFormatter.ts` の `KEYCODE_MAP` を `uiohook-napi` のコード表に合わせて再構築し、修飾キーの重複判定も `MODIFIER_KEYCODES` で再実装。
  - TypeScript ソースに合わせて `src/shared/keyFormatter.js` も再ビルドし、Vitest での検証 (`pnpm test`) を通して正しく表示されることを確認。

## 実行・確認コマンド
```bash
nodebrew install v20.19.0
nodebrew use v20.19.0
rm -rf node_modules
pnpm install
pnpm build:main
pnpm test
```

すべて成功し、`pnpm test` は 4 件のテストが pass しています。
